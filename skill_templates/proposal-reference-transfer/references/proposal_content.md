# 新策划正文模板

用于生成完整中文策划正文。正文要完整，但保持短文本提案风格，适合后续转 PPT。

## 默认结构

```markdown
# 项目理解

用 1-3 段说明新项目的核心背景、品牌处境、受众需求和本次策划要解决的问题。

# 策划核心命题

给出一句清晰、有提案感的核心命题。

# 创意概念

说明创意名称、概念来源、情绪方向和与品牌的关系。

# 策略路径

用 3-5 个短段说明从用户洞察到内容表达、现场体验或传播动作的完整逻辑。

# 内容模块

## 模块一：[名称]
- 模块目标：
- 核心内容：
- 体验/传播方式：
- 亮点：

## 模块二：[名称]
- 模块目标：
- 核心内容：
- 体验/传播方式：
- 亮点：

## 模块三：[名称]
- 模块目标：
- 核心内容：
- 体验/传播方式：
- 亮点：

# 活动/传播机制

说明节奏、触点、参与方式、扩散方式和闭环。

# 视觉与体验方向

说明主视觉、空间、影像、互动、物料或内容风格。

# 执行亮点

列出 3-5 个能被客户记住的亮点。

# 预期效果

说明品牌、用户、传播或业务层面的结果。
```

## 风格要求

- 使用中文。
- 句子短，信息密度高。
- 避免空泛词堆叠，如“赋能、焕新、沉浸式升级”单独出现时要改写为具体表达。
- 每个模块都要能支撑一页或多页 PPT。
- 不要只写标题，必须写出正文内容。
