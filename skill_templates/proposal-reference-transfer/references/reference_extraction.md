# 参考策划提炼模板

用于从原始参考策划中提炼可迁移方法。不要把参考策划改写成长摘要；重点是提炼可复用的策略、结构和表达方法。

## 输出结构

```markdown
# 原策划概览
- 项目/客户：
- 目标：
- 受众：
- 场景：
- 交付物：

# 核心策略逻辑
- 策略判断：
- 解决的问题：
- 说服路径：

# 创意概念
- 核心命题：
- 创意母题：
- 情绪关键词：

# 叙事结构
- 开场方式：
- 中段推进：
- 高潮/转折：
- 收束方式：

# 内容模块
- 模块 1：
- 模块 2：
- 模块 3：

# 执行节奏
- 前期：
- 中期：
- 现场/发布：
- 后续传播：

# 视觉语言
- 色彩：
- 材质：
- 画面氛围：
- 空间/镜头语言：

# 可迁移方法
- 可迁移 1：
- 可迁移 2：
- 可迁移 3：

# 不可迁移内容
- 不可迁移 1：
- 不可迁移 2：
- 原因：

# 证据来源摘要
- 来源文件/页面/段落：
- 证据强度：原始资料 / 二手摘要 / 用户口述
```

## 提炼要求

- 优先引用原始资料中的策略结构和执行方法。
- 避免保留旧客户、旧品牌、旧场景中不可复用的词。
- 如果参考资料证据不足，明确标注。
- 如果参考策划本身质量不高，指出不建议迁移的部分。
